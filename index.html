안동 지도 기반 채용공고 검색

프로젝트 소개

사람인 Open API와 지도 서비스를 활용하여 채용공고를 실제 근무 위치를 중심으로 탐색할 수 있도록 하는 취업 포트폴리오 프로젝트입니다.

기존의 채용공고 목록 중심 검색에서 벗어나, 지도에서 주변 채용공고를 확인하고 직무, 경력, 급여, 근무형태 등의 조건으로 검색할 수 있는 프로토타입을 개발합니다.

개발 범위

초기 개발 지역은 경상북도 안동시이며, 향후 지도상에서 채용공고 위치 표시 및 상세공고 연결 기능을 구현할 예정입니다.

현재 개발 중인 프로토타입입니다.

채용정보 제공: 사람인 Open API
